# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [1.0.0] - 2024-01-01

### Added
- Initial release of PdfEdtr
- Cross-platform support for Android, iOS, Windows, macOS, and Linux
- Basic PDF viewing functionality
- File picker integration for selecting PDF files
- Offline-first architecture
- Material Design 3 UI
- Comprehensive documentation (README, CONTRIBUTING, PLATFORM_SETUP)
- Unit and widget tests

### Features
- Open PDF files from device storage
- Cross-platform compatibility
- Clean and intuitive user interface
- No internet connection required
